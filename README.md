# GOG 2nd Class search

**[Open the site](https://toro-.github.io/2ndClassGoG/)**

A searchable version of [Games that treat GOG customers as 2nd Class](https://docs.google.com/spreadsheets/d/14haGnU2kcY6wV6ssBeyW6_mMk6kkVqZX-QvMKlgXGu0/), a Google Sheet kept up to date by volunteers from the GOG community. It lists games whose GOG release lags behind other stores, usually Steam: missing updates, DLC, languages, soundtracks, features or platform builds.

You can search titles, companies and issue text, filter by category, publisher or developer, and see totals on the Stats page.

This is an unofficial, personal search tool. It isn't made by or affiliated with GOG or the list's maintainers.

## Corrections and new reports

The sheet is the source of truth, and this site is only a copy of it. To report a game or a correction, use the [GOG forum thread](https://www.gog.com/forum/general/games_that_treat_gog_customers_as_second_class_citizens_v2). Changes appear here the next time the site is updated, and the header on the site shows the date of the sheet it's using.

## Cover art

Cover images belong to their publishers. None are stored in this repository: the page links to the images where they're already hosted, mostly on GOG's and Steam's servers, plus a few other sites for covers picked by hand. Your browser loads them directly from those sites when you view the page.

## About this repository

This repository holds only the generated site: one page, its scripts and styles, and a data file made from the sheet. Everything runs in your browser, and GitHub Pages serves the files.
